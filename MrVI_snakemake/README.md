# Historical MrVI workflow

This directory preserves the original MrVI-only scripts used during development of the study. They contain machine-specific paths and historical dependency assumptions.

For new runs of **scVI, MrVI, or LDVAE**, use the repository's root [Snakefile](../Snakefile), [configuration](../config/config.yaml), and [setup instructions](../README.md). The unified workflow supports both full-gene and HVG inputs, model-specific parameters, saved models, scIB evaluation, and combined results tables.
